# MediCenter-ді интернетке шығару (тегін, тек Render)

Сайт та, дерекқор да **Render**-де тұрады. Тек бір аккаунт керек, ол GitHub арқылы ашылады, карта сұралмайды. Компьютер өшіп тұрса да, сайт жұмыс істей береді.

## Қадамдар
1. https://render.com сайтына кіріп, **Get Started** → **GitHub** арқылы тіркеліңіз.
2. **New +** → **Blueprint** басыңыз.
3. **Connect GitHub** арқылы Render-ге `medicenter` репозиторийін көруге рұқсат беріп, оны таңдаңыз.
4. **Blueprint Name** өрісіне `medicenter` деп жазып, **Deploy Blueprint** (немесе **Apply**) басыңыз. Ешқандай пароль енгізудің керегі жоқ, Render сайтты (`medicenter`) да, дерекқорды (`medicenter-db`) да өзі құрады.
5. 3–5 минут күтіңіз. Сосын **Dashboard** → `medicenter` сервисін ашыңыз. Жоғарыда `https://medicenter-xxxx.onrender.com` сілтемесі тұрады.

Сервер бірінші рет іске қосылғанда кестелер мен демо деректерді өзі құрады. Бұл сілтемені кез келген адамға жіберуге болады, телефоннан да ашылады.

## Тегін нұсқаның шектеулері
- 15 минут бойы ешкім кірмесе, сайт ұйықтап қалады. Келесі адам кіргенде шамамен 1 минутта оянады.
- Render-дің тегін PostgreSQL дерекқоры **30 күн** жұмыс істейді. Сосын Render оны тоқтатады, тағы 14 күннен кейін өшіреді. Сайт ұзақ тұруы керек болса, мерзім біткенше төмендегі Neon-ға көшіріңіз.

## Тұрақты тегін дерекқор (Neon)
1. https://neon.tech сайтында GitHub арқылы тіркеліп, `medicenter` деген жоба ашыңыз.
2. **Connection string** мәнін көшіріңіз (`postgresql://...neon.tech/neondb?sslmode=require`).
3. Render-де `medicenter` сервисі → **Environment** → `DATABASE_URL` мәнін осы жолмен ауыстырып, **Save Changes** басыңыз.

Сайт қайта іске қосылғанда жаңа дерекқорды демо деректермен өзі толтырады.

## Жаңарту
GitHub-тағы `main` тармағы өзгерген сайын Render сайтты автоматты түрде қайта жинайды.

## Қате шықса
`medicenter` сервисінің **Logs** бөлімін ашып, қызыл жолдардың скриншотын жіберіңіз.
- `Database check failed` шықса, дерекқор әлі дайын емес. 1–2 минут күтіп, **Manual Deploy → Restart service** басыңыз.

## Компьютердегі SQL Server
Компьютерде бұрынғыдай SQL Server қолданылады: `DATABASE_URL` бос болса, сервер `server/.env` ішіндегі `DB_*` мәндерімен қосылады.

# MediCenter

Астана қаласындағы медициналық орталықтарды іздеу және қабылдауға жазылу платформасы.
*Денсаулыққа бірге қадам.*

## Қазіргі кезең: интерфейс прототипі

- Басты бет: іздеу жолағы, танымал мамандықтар, ұсынылған клиникалар
- Клиникалар каталогы: мамандық, аудан және баға бойынша сүзгілер
- Клиника профилі: филиалдар, дәрігерлер, қызметтер мен бағалар
- 4 қадамды жазылу: филиал мен дәрігер → қызмет → күн мен уақыт → байланыс деректері (валидациямен)
- Қазақ / орыс тілдері, телефонға бейімделген дизайн

Деректер ойдан шығарылған (`src/data/clinics.js`), жазылу әзірге серверге жіберілмейді.
Келесі кезең: Node.js/Express + MySQL backend.

## Іске қосу

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/ қалтасына жинау
```

## Технологиялар

React 18, Vite, Tailwind CSS 4, React Router. Түстер брендбуктан: `#0E3A6B`, `#06B6D4`, `#7EE7DB`, `#F3F6FB`.

# MediCenter

Астана қаласындағы медициналық орталықтарды іздеу және қабылдауға жазылу платформасы.
*Денсаулыққа бірге қадам.*

## Мүмкіндіктер

| Рөл | Не істей алады |
| --- | --- |
| Қонақ | Клиникаларды іздеу, мамандық/аудан/баға бойынша сүзу, клиника профилі мен пікірлерді көру, клиника ретінде өтінім беру |
| Пациент | Тіркелу, кіру, 4 қадамда дәрігерге жазылу, алдағы жазылуды болдырмау, аяқталған қабылдауға пікір қалдыру |
| Дәрігер | Өз кестесі мен қабылдауларын көру |
| Клиника әкімшісі | Жазылуларды растау/аяқтау/болдырмау, дәрігерлер, қызметтер, филиалдар мен профильді басқару |
| Платформа әкімшісі | Клиника өтінімдерін мақұлдау/қабылдамау, «Ұсынылған» және «Жарнама» белгілері |

Негізгі ережелер серверде тексеріледі: бір уақытқа бір дәрігерге тек бір пациент жазыла алады (транзакция + жол құлпы),
клиника әкімшісі тек өз ұйымының деректерін көреді (multi-tenant), пікірді тек аяқталған қабылдаудан кейін бір рет қалдыруға болады,
өтінімі мақұлданбаған клиника каталогта көрінбейді.

## Технологиялар

- **Frontend:** React 18, Vite, Tailwind CSS 4, React Router — `src/`
- **Backend:** Node.js, Express, REST API + JSON, JWT, bcrypt — `server/src/`
- **Дерекқор:** Microsoft SQL Server 2016+ (Express та болады) — `server/sql/schema.sql`
- **Тесттер:** 12 API тесті (`node:test`) — `server/test/`

## Компьютерде іске қосу

Қажет: Node.js 22+ және SQL Server (SSMS арқылы баптаймыз). Толық нұсқаулық: [docs/sql-server-setup.md](docs/sql-server-setup.md).

```bash
npm run setup     # тәуелділіктер
npm run db:init   # дерекқорды, кестелерді және демо деректерді құрады
npm run server    # API: http://localhost:3000
npm run dev       # Сайт: http://localhost:5173 (екінші терминалда)
```

Қосылу параметрлері `server/.env` файлында (`server/.env.example` үлгісінен көшіріңіз). Әдепкі мәндер:
сервер `localhost:1433`, логин `medicenter`, құпиясөз `Medicenter123!`, дерекқор `medicenter`.

Тесттер: `npm test` (алдымен `npm run db:init`).

## Интернетке жариялау

`npm run build` жасалғаннан кейін Express сервері `dist/` қалтасындағы сайтты да өзі береді, сондықтан бір Node.js сервис жеткілікті:

- Build: `npm run setup && npm run build`
- Start: `npm start`
- Айнымалылар: `server/.env.example` қараңыз (`JWT_SECRET` міндетті).
- `DATABASE_URL` берілсе, сервер SQL Server орнына PostgreSQL-ді қолданады. Бос дерекқорда кестелер мен демо деректерді бірінші іске қосылғанда өзі құрады.

Ең оңай жолы — Render Blueprint (`render.yaml`): сайт пен тегін PostgreSQL бір батырмамен ашылады. Қадамдары: [docs/deploy.md](docs/deploy.md).

GitHub Pages тек статикалық сайтты көрсетеді, сондықтан backend-пен жұмыс істемейді.
